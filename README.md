# homebrew-cleanup-tool

Homebrew tap for [`cleanup-tool`](https://github.com/patriciomg/cleanup-tool), a terminal-based disk cleanup tool for macOS.

## Install

```bash
brew tap patriciomg/cleanup-tool
brew install patriciomg/cleanup-tool/cleanup-tool
```

Homebrew 4.1+ may ask you to trust the tap first. If so, run:

```bash
brew trust patriciomg/cleanup-tool
brew install patriciomg/cleanup-tool/cleanup-tool
```

## Upgrade

```bash
brew update && brew upgrade cleanup-tool
```
